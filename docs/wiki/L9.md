# L9 Send real email with smtplib

## What we gained

- `smtplib` sends the message over SMTP with STARTTLS and a login.
- The sending is behind a `MailSender` port. The `SmtpMailSender` adapter implements it, and tests use a fake, so no real mail is sent while testing.
- The server settings come from `MAIL_*` environment variables; the project never reads a `.env` file and no secret is in the repository.
- If the mail server is not configured or fails, the visitor sees *Your message could not be sent* (HTTP 502) instead of a false success.
- The screenshots were made in Docker with a local mail sink that received the message, which proves delivery without a real mailbox.

## Where it is in the code

- `src/html_forms/application/ports/mail_sender.py`
- `src/html_forms/application/use_cases/send_contact_message.py`
- `src/html_forms/infrastructure/mail/smtp_mail_sender.py`
- `src/html_forms/infrastructure/config/mail_settings.py`
