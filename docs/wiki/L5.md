# L5 The blog and its contact link

## What we gained

- The blog from Day 59 gets a contact page with a form, linked from the navigation.
- The blog is built from layers: a `Post` entity, a `PostRepository` port and a JSON repository, so the views stay small.
- The Day 60 starting files could not be downloaded, so the blog is rebuilt from the lecture description with plain CSS (no CDN).

## Where it is in the code

- `src/html_forms/presentation/features/blog/app.py` (`BlogViews.home`, `about`, `show_post`)
- `src/html_forms/presentation/features/blog/templates/`
