# L5 Blog dan pautan hubungi

## Apa yang kita peroleh

- Blog daripada Hari 59 mendapat halaman hubungi dengan borang, dipautkan dari navigasi.
- Blog dibina daripada lapisan: entiti `Post`, port `PostRepository` dan repositori JSON, supaya paparan kekal kecil.
- Fail permulaan Hari 60 tidak dapat dimuat turun, jadi blog dibina semula daripada huraian kuliah dengan CSS biasa (tanpa CDN).

## Di mana dalam kod

- `src/html_forms/presentation/features/blog/app.py` (`BlogViews.home`, `about`, `show_post`)
- `src/html_forms/presentation/features/blog/templates/`
