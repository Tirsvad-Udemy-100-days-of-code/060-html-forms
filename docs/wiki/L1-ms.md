# L1 Hidangkan halaman HTML

## Apa yang kita peroleh

- Flask menjadikan fungsi Python sebuah halaman web: `home()` diikat kepada `/` dan mengembalikan `render_template("index.html")`.
- Fail HTML berada dalam folder `templates`, yang ditemui oleh Flask sendiri.
- Sebuah halaman hanya memerlukan `<h1>` untuk membuktikan pelayan berfungsi.

## Di mana dalam kod

- `src/html_forms/presentation/features/login/app.py` (`home`)
- `src/html_forms/presentation/features/login/templates/index.html`
