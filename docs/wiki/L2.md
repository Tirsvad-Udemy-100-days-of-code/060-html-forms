# L2 Build a login form

## What we gained

- An HTML form is a `<form>` with `<input>` elements; the browser draws the fields.
- Each input needs a `name` attribute, because that is the key the server later reads.
- `type="password"` hides the characters while typing, but it does not protect the data on its own.

## Where it is in the code

- `src/html_forms/presentation/features/login/templates/index.html`
