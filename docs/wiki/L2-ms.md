# L2 Bina borang log masuk

## Apa yang kita peroleh

- Borang HTML ialah `<form>` dengan elemen `<input>`; pelayar melukis medan-medan itu.
- Setiap input memerlukan atribut `name`, kerana itulah kunci yang dibaca oleh pelayan kemudian.
- `type="password"` menyembunyikan aksara semasa menaip, tetapi tidak melindungi data dengan sendirinya.

## Di mana dalam kod

- `src/html_forms/presentation/features/login/templates/index.html`
