# L3 Send the form with POST

## What we gained

- `action="/login"` says where the browser sends the data and `method="post"` says how.
- GET puts the data in the URL; POST puts it in the body of the request, so it is not shown in the address bar.
- A route must allow the method: the `/login` route accepts `POST` only.

## Where it is in the code

- `src/html_forms/presentation/features/login/templates/index.html` (the `<form>` tag)
- `src/html_forms/constants.py` (`ROUTE_LOGIN`)
