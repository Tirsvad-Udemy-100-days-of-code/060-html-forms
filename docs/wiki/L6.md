# L6 The form-entry route

## What we gained

- A second route, `/form-entry`, receives the form with `POST` and returns the data as an `<h1>`.
- It proves the round trip browser, request, server, response before any email is involved.
- The view logs only the field names, never what the visitor typed.

## Where it is in the code

- `src/html_forms/presentation/features/blog/app.py` (`BlogViews.form_entry`)
- `src/html_forms/constants.py` (`ROUTE_FORM_ENTRY`)
