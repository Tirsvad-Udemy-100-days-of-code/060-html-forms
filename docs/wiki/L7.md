# L7 One route for GET and POST

## What we gained

- One route, `/contact`, can serve both the empty form (GET) and the submitted form (POST).
- The view checks `request.method` and branches, which removes the second URL.
- The submitted text is validated by the `ContactMessage` entity: fields are trimmed, line breaks in the sender or subject are rejected and an empty message is refused.

## Where it is in the code

- `src/html_forms/presentation/features/blog/app.py` (`BlogViews.contact`)
- `src/html_forms/domain/entities/contact_message.py`
