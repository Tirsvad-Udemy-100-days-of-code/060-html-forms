# L4 Receive the form data

## What we gained

- `request.form["name"]` reads a submitted field by the `name` attribute from L2.
- `receive_data()` answers with an `<h1>` holding the name and the password, like the lecture.
- The values are escaped with `markupsafe.escape`, so a name such as `<script>` cannot inject HTML.
- Echoing a password is only for the lesson; a real application never does this, and this project never logs the values.

## Where it is in the code

- `src/html_forms/presentation/features/login/app.py` (`receive_data`)
