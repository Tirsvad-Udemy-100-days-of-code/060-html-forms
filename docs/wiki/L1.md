# L1 Serve an HTML page

## What we gained

- Flask turns a Python function into a web page: `home()` is bound to `/` and returns `render_template("index.html")`.
- HTML files live in a `templates` folder, which Flask finds by itself.
- A page needs only an `<h1>` to prove the server works.

## Where it is in the code

- `src/html_forms/presentation/features/login/app.py` (`home`)
- `src/html_forms/presentation/features/login/templates/index.html`
